# arena-cli

Use **https://arena.ai/agent** from the command line through a real browser: ask a question, wait for Agent Mode to finish, and retrieve its answer and generated files.

```bash
arena ask "Research the pricing strategies of three competitors"  # Print the answer directly to stdout
arena workspace download --all --out ws.zip                     # Bundle files generated by the Agent
```

`arena.ai/agent` is a general-purpose web agent that can research topics, write documents, run code, and produce files, but it has no public API.
This project provides the missing command-line layer: no API key is required because it uses the website itself. Log in once by importing browser cookies, then reuse that authenticated session.

## Why use it

- **One prompt, one answer**: `arena ask` submits your prompt and automatically waits for the Agent to finish. stdout contains only the answer, so it can be redirected or piped directly.
- **Multi-turn and background execution**: use `--chat last` to continue the previous conversation; use `--no-wait` to run in the background and `arena jobs result` to retrieve the result.
- **Access generated files**: use `show` to read `.md`/`.csv` files from the Agent workspace and `download` to save them.
- **Designed for scripts and agents**: `--json` provides a consistent envelope, failures include next-step hints, exit codes are machine-readable, and `arena schema` supports command introspection.

## Installation

```bash
git clone https://github.com/chenty/arena-cli.git && cd arena-cli
pip install -e .                          # Install the arena command (or run ./bin/arena without installing)
python -m playwright install chromium     # One-time browser installation
```

To use it as a slash command in Hermes, install the skill as well:

```bash
./install.sh        # → ~/.hermes/skills/arena-cli; then run /arena-cli your question
```

## Log in (once)

The recommended method is a cookies file exported from your browser. Netscape `cookies.txt`, Cookie-Editor JSON, and Playwright storage_state formats are detected automatically:

```bash
arena cookies import ~/Downloads/arena.ai_cookies.txt
arena check                       # Confirm that the session is still authenticated
```

If you do not have a cookies file, use email login instead. This opens a browser so you can click the email link: `arena login --email you@example.com --headed`.
Use `--profile` to isolate multiple accounts: `arena profile create work --from work_cookies.txt` followed by `arena profile use work`.

## Common commands

| Command | Purpose |
| --- | --- |
| `arena ask "question"` | Ask a question and print the answer (`--json` / `--stream` / `--no-wait` / `--chat last`) |
| `arena check` | Check authentication (`--probe` sends a real verification message) |
| `arena status` | Offline overview of sessions, configuration, and background jobs without opening a browser |
| `arena cookies import\|export\|show` | Import/export cookies or list them (names only) |
| `arena chat list\|open` | Recent conversations |
| `arena workspace list\|show\|download` | Conversation workspace: list files, read contents, or download them (`--all` creates an archive) |
| `arena jobs list\|status\|result` | Manage background jobs created by `ask --no-wait` |
| `arena profile list\|create\|use` | Switch between authenticated sessions |
| `arena config list\|set` | Change timeouts, proxies, and selectors |
| `arena doctor` | Check dependencies, browser, network, session, and skill installation |

For complete options, run `arena --help` or `arena schema <command>`, or see [docs/cli.md](docs/cli.md).

## Security

`~/.arena-cli/state.json` contains account credentials (its permissions are set to 600): never commit it to Git or paste it into a chat.
Passwords never pass through this tool; authentication uses an email magic link or one-time code. Use it only with your own account, serially and at a low request rate, and comply with the site's terms.
